CampusConnect - current project snapshot

1. Install Node.js 22.13 or newer.
2. Extract the ZIP and open a terminal in campus-connect.
3. Run: npm install -g pnpm@11.25.0
4. Run: pnpm install --frozen-lockfile
5. Run: node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000
6. Open http://127.0.0.1:3000
